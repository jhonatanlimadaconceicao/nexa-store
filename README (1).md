# Nexa Store — Protótipo de Dropshipping

Projeto inicial em React + Vite.

## O que já funciona
- Vitrine de produtos
- Página de produto
- Carrinho
- Remoção de produtos
- Cálculo do total
- Navegação mobile
- Painel administrativo visual

## Como executar

1. Instale Node.js.
2. Abra esta pasta no terminal.
3. Execute:

```bash
npm install
npm run dev
```

4. Abra o endereço mostrado pelo Vite.
